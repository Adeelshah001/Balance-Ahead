# Balance Ahead

Balance Ahead is an offline Android expense tracker for planning around income and bills.

- Track one-time and recurring income and expenses, with custom schedules and optional end dates.
- See projected balances and break-even dates in the dashboard and calendar.
- Keep the dashboard, recent entries, or calendar on your home screen with widgets.
- Back up and restore your entries using local files.

Requires Android 8.0 or later. Get the APK from [GitHub Releases](https://github.com/Adeelshah001/Balance-Ahead/releases).
